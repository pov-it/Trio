# AutoPresets (in-repo)

Activity-based override presets used with AI Hub / Settings. This folder is part of the Trio app target, **not** a git submodule or Swift package (same rule as [`../AIInsights/README.md`](../AIInsights/README.md)).

Wired from `Settings` → Feature settings → AutoPresets and `AppDelegate` (`AutoPresetsCoordinator.shared.startIfConfigured()`).
